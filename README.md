# CodeForces — CP-31 Sheet Solutions

![Java](https://img.shields.io/badge/language-Java-orange)
![Progress](https://img.shields.io/badge/problems-1%2F248-blue)

My solutions to the **[CP-31 Sheet](https://www.tle-eliminators.com/cp-sheet)** by Priyansh Agarwal (TLE Eliminators) — 31 hand-picked Codeforces problems for every rating level from **800 to 1500**, solved in Java.

## About the Sheet

The CP-31 sheet isn't a random problem dump — each problem was picked to teach a specific concept, pattern, or trick useful in competitive programming. The idea is simple: solve 1 problem a day, 31 days per rating band, and level up steadily from beginner to intermediate CP.
